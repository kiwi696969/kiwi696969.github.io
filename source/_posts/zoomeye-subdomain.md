ZoomEye（钟馗之眼）是一个针对网络空间的搜索引擎。它主要收集网络中的主机、服务器等信息，并对这些数据进行整理和整合，是面向网络空间的搜索引擎。

## 一、强大的网络空间搜索引擎：ZoomEye

### 主要特点和功能

- **广泛的网络覆盖**：ZoomEye 能够扫描整个互联网，覆盖全球范围内的网络设备和服务。
- **详尽的信息收录**：收录了大量网络设备和服务的详细信息，包括但不限于 IP 地址、地理位置、开放端口、服务类型等。
- **实时更新**：持续进行网络扫描，确保数据库中的信息是最新的。
- **可视化界面**：提供直观的搜索界面和结果展示，用户可以轻松地进行搜索和筛选。
- **设备搜索**：可以按设备类型、操作系统、服务、端口等条件进行搜索。
- **服务搜索**：可以搜索特定的服务，如 HTTP、HTTPS、FTP、SSH 等。
- **端口扫描**：显示设备开放的端口及其对应的服务信息。
- **地理位置信息**：展示设备的地理位置，帮助了解网络资产的分布情况。
- **指纹识别**：识别设备的指纹信息，包括设备类型、厂商、型号等。
- **漏洞关联**：与漏洞数据库关联，提示设备可能存在的安全漏洞。
- **可视化展示**：通过地图、图表等形式直观展示搜索结果和数据分析。
- **API 接口**：提供 API 接口，方便开发者把 ZoomEye 的功能集成到自己的工具或系统中。
- **高级搜索**：支持高级搜索选项，如正则表达式搜索、结果过滤等。
- **数据导出**：允许将搜索结果导出为 CSV 或其他格式，便于进一步分析。

### 关键词语法

可以通过关键词搜索内容。ZoomEye 支持的关键词如下：

| 关键词 | 说明 |
|---|---|
| `app` | 组件名称 |
| `ver` | 组件版本 |
| `port` | 搜索端口号 |
| `os` | 搜索指定的操作系统 |
| `service` | 服务名称 / 服务类型 |
| `country` | 国家名 |
| `city` | 城市名 |
| `device` | 搜索指定的设备类型，如 `device:router` |
| `ip` | 搜索特定的 IP 地址 |
| `cidr` | 指定的 CIDR 网段 |

举例：

```
app:apache ver:2.4          搜索 Apache 2.4
port:22                     搜索开放了 SSH 端口的主机
service:SSH                 搜索 SSH 服务
os:linux                    搜索 Linux 主机
country:China city:Beijing  搜索北京的主机
ip:192.168.1.1              搜索指定 IP
cidr:192.168.158.12/24      搜索指定网段
service:http                搜索 HTTP 服务
```

也可以不用关键词，直接输入普通词。比如输入「地址」，ZoomEye 会提示 `http.body="地址"`，即在 HTML 正文里搜索包含这个词的资产：

## 二、其他功能类似的网络空间搜索引擎

### Shodan

https://www.shodan.io/

Shodan 被广泛认为是网络空间搜索引擎的鼻祖，能够扫描互联网上的设备，并索引其服务信息。

![Shodan 首页](/img/zeye-04.png)

### Censys

https://search.censys.io/

Censys 由密歇根大学的研究人员开发，类似于 Shodan，专注于扫描 IPv4 地址空间，收集有关主机和服务的信息。

![Censys 首页](/img/zeye-05.png)

### FOFA

https://fofa.info/

FOFA 是一个中文的网络空间安全搜索引擎，提供主机和服务器的搜索。

![FOFA 首页](/img/zeye-06.png)

## 三、子域名收集

以搜索 `guet.edu.cn` 的子域名为例，既可以使用上面这些网络空间搜索引擎，也可以使用在线网站：

https://tools.yum6.cn/Tools/urlblast/

该工具按字典对目标域名做爆破，命中的子域名连同解析到的 IP 一起列出来——`www`、`mail`、`smtp`、`oa`、`portal`、`download`、`dns` 这些常见前缀几乎每次都能命中：
